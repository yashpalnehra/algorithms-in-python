# Strings

Anagrams, palindromes and a few substring problems.

- `anagrams.py`, check two strings and group a list of words by their sorted letters.
- `palindromes.py`, a cleaned-up palindrome check and the longest palindromic substring.
- `substrings.py`, longest run without repeats (sliding window), reversed words, run-length encoding.

Tests: `python3 -m pytest`.

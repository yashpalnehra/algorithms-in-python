# Algorithms in Python

Classic data structures and algorithms, each written from scratch and covered by tests. The folders go from array warm-ups to graphs and dynamic programming. Only the standard library is used, plus pytest for the tests.

1. `01-arrays`, two sum, maximum subarray, rotation, duplicates.
2. `02-strings`, anagrams, palindromes, sliding window, run-length encoding.
3. `03-searching-and-sorting`, binary search, insertion, merge and quick sort.
4. `04-stacks-and-queues`, a stack, a min stack, a queue from two stacks, balanced brackets, RPN.
5. `05-linked-lists`, a singly linked list and cycle detection.
6. `06-hash-maps`, an LRU cache and counting problems.
7. `07-trees`, a binary search tree with delete, traversals, balance, lowest common ancestor.
8. `08-graphs`, BFS, DFS, shortest path, components, Dijkstra, topological sort.
9. `09-dynamic-programming`, Fibonacci, LCS, edit distance, coin change, knapsack, LIS.

Run everything with `python3 -m pytest` from the root, or cd into a folder and run it there.

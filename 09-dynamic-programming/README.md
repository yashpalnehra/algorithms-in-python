# Dynamic programming

- `sequences.py`, Fibonacci with memoisation and with a loop, climbing stairs, longest common subsequence and edit distance.
- `knapsack.py`, fewest coins for an amount, the 0/1 knapsack in one row, and the longest increasing subsequence.

Each function keeps a small table of answers to subproblems instead of recomputing them. Tests: `python3 -m pytest`.
